# Markdown機能の点検

点検日：2026-11-16。ソースコード・既存の仕様・単体テスト・ブラウザ操作を照合した。対象は通常ノート、テーマの月次ページ、資料ページの本文エディタ。以下の「対応」はこのアプリ内での編集・表示を示し、他のMarkdownエディタの対応範囲やPDFの完成を示すものではない。

## 基本操作

| 機能 | 状態と操作 | 確認内容・制限 |
| --- | --- | --- |
| 太字 | Ctrl+Bで適用・解除 | 選択、空の位置、既存の`__`、入れ子、Undo/Redo、保存を検証。空の位置では対の記法を挿入して内側へ移動する。 |
| 斜体 | Ctrl+Iで適用・解除 | 既存の構文選択キーとの競合を解消し、ブラウザで検証。 |
| 取り消し線 | Ctrl+Shift+Xで適用・解除 | `~~文字~~`の整形表示も今回追加。エスケープやコード内の同じ文字列とは構文で区別する。 |
| インラインコード | Ctrl+Eで適用・解除 | 選択内のバッククォートより長い区切りを選択し、端の空白を保持する。 |
| 通常リンク | Ctrl+Kで挿入・参照先編集 | 選択した文章をラベルとし、URL部分を選択して入力を待つ。URLの貼り付けに資料登録が割り込まないよう修正。 |
| コードブロック | Ctrl+Shift+Cで追加・解除 | 選択した行を囲む。空の位置、内側にコードフェンスがある選択、解除を検証。引用・リスト内部は手入力で編集する。言語名は開始フェンスで編集する。 |
| 見出しH1〜H6 | Ctrl+Alt+1〜6で設定、Ctrl+Alt+0で解除 | ATX・Setext、複数行、引用内の見出しに対応。リスト内は階層を崩さないため変換しない。 |
| 箇条書き | Ctrl+Shift+8で追加・解除 | 親の記号を除くと子孫を昇格し、意図せずインデントコードにしない。タスク解除時も`[ ]`を残さない。 |
| 番号付きリスト | Ctrl+Shift+7で追加・解除 | 変換時は選択した兄弟ごとに1から連番を付ける。表示は元ファイルの番号を保持し、手書きの全番号を常時再計算するものではない。 |
| 引用 | Ctrl+Shift+.で追加・解除 | 複数選択では全行が引用なら1段解除し、混在時は未引用行を引用にする。コード・YAMLを変更しない。 |
| チェックボックス | Ctrl+Lで作成・完了切り替え、クリックでも切り替え | 表示、Enter補完、複数選択、Undo、月次ページの上下移動と保存を検証済み。 |
| リスト構造 | Tab、Shift+Tab、Enter、Shift+Enter、Backspace、Delete、Alt+上下 | 親のない字下げを禁止し、子孫の移動・結合、月境界、キャレットの位置を既存テストと照合。 |
| 折り畳み | 見出し左の矢印、Ctrl+Shift+[／]、Ctrl+Alt+[／] | 月境界・親子・目次ジャンプ、タブと再起動後の復元を検証済み。 |
| Undo/Redo | Ctrl+Z、Ctrl+Shift+Z | 書式操作をそれぞれ独立した履歴にする。 |

書式コマンドは物理ファイルごとに処理する。複数行のインライン装飾は行ごとの本文へ適用し、リスト記号・タスク記号・見出し記号と仮想月区切りを囲まない。コード・YAML・HTML・リンク先は通常の装飾対象から外す。表示を切り替えただけではMarkdownを書き換えない。

## 記法と表示

| 記法 | 状態 |
| --- | --- |
| H1〜H6、Setext見出し | 整形表示・編集・目次・折り畳みに対応。 |
| 太字、斜体、入れ子、エスケープ | 対応。編集行では元記法を表示。 |
| 取り消し線 | 今回追加。 |
| 水平線 | 今回追加。編集中は元記法、編集行を離れると罫線を表示する。元の行の高さを維持する。 |
| 箇条書き・番号・タスク・引用 | 対応。番号は元の記法を表示する。 |
| インラインコード、バッククォート／チルダのフェンス、インデントコード | 基本表示に対応。 |
| 通常リンク、参照形式、山括弧の自動リンク | 表示・編集に対応。内部ノート・資料リンクの既存操作も継続。 |
| Wikilink | `[[`補完、新規作成、日付リンク、参照元に対応。 |
| 画像、既知のimg属性 | 表示・サイズ変更・注釈に対応。任意のHTMLやスクリプトは実行しない。 |
| 表 | **未実装**。記法は保存できるが、セルの整形表示・Tabによるセル移動・行列の編集UIはない。 |
| 数式 | **未実装**。`$...$`や`$$...$$`の組版表示はない。 |
| コードの言語別ハイライト | **未実装**。コード用の背景・等幅表示とフェンスの言語名表示まで。 |
| 脚注、Mermaid、コールアウト、`==ハイライト==`など | 専用の表示・操作は未実装。初期仕様で対応を確定した機能とは分けて扱う。 |
| PDF | **未実装**。Markdownの画面表示に対応していても、PDFへ正しく出力できることは確認していない。 |

## 残る編集機能・検証

- 文書内の検索・置換専用UI（Ctrl+F／Ctrl+H）は未実装。保管庫全体の検索はCtrl+Shift+Fで使用できる。
- Markdown記法を手で入力したときの、汎用的な括弧・引用符の自動対入力は未実装。上記の書式ショートカットは対を挿入する。
- 番号付き項目をAlt+上下で入れ替えた後の番号は元記法を保持する。常時の自動再採番は未実装。
- 手入力でH1の日付そのものを装飾した場合の「今日へ」・日付リンクの扱いは引き続き調整対象。日付見出しは`# YYYY-MM-DD`の形式を基本とする。
- 今回の確認はブラウザUIと単体テストによる。日本語IME変換中、Windowsの各表示倍率、Windowsネイティブでの全ショートカットの確認までは完了として扱わない。

今回、文字の書式ショートカット、取り消し線・水平線の表示、URL編集中の貼り付けを補った。表・数式・ハイライトなど上記の残項目を含めて、Markdown機能全体が完成したとは扱わない。

検証結果：型検査、全単体96件、全ブラウザ89件が通過。さらにキャレット保持の単体テストを追加し、書式操作13件を再確認した（単体合計97件）。WindowsリリースビルドとNSISインストーラーを生成済み。
